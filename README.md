# UNDERTALE BATTLE EMULATOR

Undertale風の弾幕バトルを自作できるブラウザ製エディタ。骨(ボーン)にキーフレームを打って位置・回転・出現タイミングをデザインし、実際に魂(ハート)を動かして自作の攻撃を遊べます。

- 遊ぶ: https://kaikomziu.github.io/undertale-battle-emulator/

## 機能

- **エディタ**: 「種類」を選んでから追加(通常/青/オレンジ/ブラスターを最初から選べる)。キャンバス上のドラッグ(移動)・回転ハンドル(回転)で現在時刻にキーフレームを自動作成/更新
- **パターン複製**: 編集中の攻撃をまるごと複製して新しい編集を開始(元のパターンは自動保存されて残る)
- **キーフレーム項目**: 位置・回転・拡大率・不透明度に加えて、長さ・太さもキーフレームごとに個別指定可能(骨が伸び縮みする演出が作れる)。未指定のキーフレームは骨の初期値にフォールバック
- **途中で消す/出す**: タイムラインを狙った時刻に合わせて「この時刻で消す」「この時刻で出現」を押すだけで、その瞬間に骨を非表示(当たり判定も消える)/表示にするキーフレームを打てる
- **骨の種類**: 通常(白)/青(動くと被弾)/オレンジ(止まると被弾)/ブラスター(溜めて発射するビーム攻撃)
- **補間モード**: 直線 / イーズ(滑らかな加減速)を骨ごとに切り替え可能
- **反転複製**: 選択中の骨をX座標・回転を反転した鏡合わせでコピー
- **タイムライン**: 各骨のキーフレームをマーカー表示(骨の色で識別)。ドラッグで時刻変更、クリックで選択・数値編集
- **プレビュー再生**: 攻撃パターン全体をその場でアニメーション確認
- **プレイモード**: 矢印キー/WASD(スマホは画面下の十字ボタン)で魂を操作し、実際に骨を避けて攻撃時間を耐えきる。被弾時は画面シェイク+赤フラッシュ、ノーダメージクリアには専用表示
- **効果音**: WebAudio自作合成(被弾・勝利・敗北・決定音)。外部音源は不使用、右上の🔊で切り替え可能
- **テンプレート**: 横なぎ骨・回転する骨・隙間の壁・十字連打・波状の骨・青とオレンジ・ガスターブラスター・伸び縮みする骨の8種類のサンプルパターンを収録
- **保存**: ブラウザのローカルストレージに保存、またはJSONファイルとして書き出し/読み込み
- **みんなの作品**: 「🌐 公開」でSupabase上の共有ギャラリーに攻撃パターンを公開。「ライブラリ」→「みんなの作品」から誰でも他の人の作品を見つけて遊べる(ニックネーム省略可、公開後の削除・編集は不可)

## 構成

- `index.html` / `css/style.css`
- `js/data.js` — データモデル・保存・テンプレート
- `js/render.js` — キーフレーム補間・描画・当たり判定(骨の種類ごとの被弾ルールを含む)
- `js/sfx.js` — WebAudio効果音の自作合成
- `js/community.js` — Supabase共有ギャラリー(公開・一覧取得)
- `js/editor.js` — エディタ画面のロジック
- `js/player.js` — プレイ(バトル)画面のロジック
- `js/main.js` — 画面切り替え・ライブラリ・保存/書き出しの配線

## 共有ギャラリーのバックエンド

Supabaseの`utbe_patterns`テーブル(name, author, pattern jsonb, created_at)に公開データを保存。RLSで誰でもSELECT/INSERT可能、UPDATE/DELETEは不可(公開後は編集・削除できない一方向の投稿)。1件あたりのJSONサイズは約190KBまでに制限。

ビルド不要、静的ファイルのみで動作します。
